# Portfolio Notes

## Resume-ready summary
Built an AI computer recommendation assistant with FastAPI, LLM intent extraction, web search, multi-dimensional scoring, and a browser-based visualization layer.

## Highlights

- Converts natural-language needs into budget, use-case, device-type, and preference constraints.
- Combines search results with deterministic scoring and explainable recommendation cards.
- Keeps the service bootable without credentials and validates the health endpoint in tests.

## Interview focus
Discuss graceful degradation, prompt/parser boundaries, ranking design, and why model access is optional at startup.

## Public-scope boundary
The public edition uses synthetic/demo product data and excludes private API keys, cookies, customer data, and platform configuration.
